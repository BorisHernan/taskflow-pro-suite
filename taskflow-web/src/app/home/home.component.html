Cómo está hecho

Un microservicio reactivo que no bloquea hilos mientras espera a la base de datos, con tiempo real en las dos direcciones y controles de abuso para una demo pública sin login.

Backend
Java 21, Spring Boot 3, Spring WebFlux, R2DBC, Flyway
Frontend
Angular 22 con componentes standalone y signals, RxJS, SCSS
Tiempo real
Server-Sent Events para difundir cambios, WebSocket para el juego
Calidad
JUnit 5, Mockito, Reactor Test, Vitest y CI en GitHub Actions
Despliegue
Docker en Render, Vercel y PostgreSQL en Neon, todo en planes gratuitos

API documentada en Swagger README con la arquitectura
